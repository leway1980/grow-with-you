# 《陪你長大》｜台灣親職人生模擬

玩家扮演台灣的父母，從孩子出生一路陪到考上大學（約 18 年；也可以從上小學開始玩）。
節奏比照《47萬分之1》：時間自動流動、事件跳出來讓你選，國小以後一年約 6 個回合，學前節奏較快。
主角是「陪伴的方式」，不是分數：同一個孩子，用不同方式陪，會長成不同的樣子。

狀態：**M1 引擎骨架可玩**（出生到國小六年級，之後以「待續」結束；內容只是最小證明，完整事件、國中高中與組合式結局是後續里程碑）。

## 在本機執行

純靜態網頁，沒有建置步驟、沒有 npm 相依套件、沒有外部 CDN（跑測試需要 Node 18+）。

```bash
python3 -m http.server          # 瀏覽器開 http://localhost:8000（?seed=123 固定家庭，?ms=300 縮短時間流動）
node --test tests/              # 測試
node tools/lint-data.mjs        # 資料檢查
node tools/simulate.mjs 500     # 策略機器人模擬：三條結果軸、幸福、參數曝光表
```

引擎在 `js/engine/`（純函式，無 DOM），資料在 `data/`。複製自《高中，只有一次》的檔案開頭都有一行來源註解。

| 文件 | 內容 |
| --- | --- |
| [docs/DESIGN.md](docs/DESIGN.md) | 玩法、數值、階段、結局、與共用標準的對應 |
| [docs/DATA.md](docs/DATA.md) | 台灣比例資料與來源；標「待確認」者尚未查到原始統計 |

引擎沿用《47萬分之1》（leway1980/47wan）已驗證的事件系統、變數槽、資料檢查、模擬器與組合式結局。
依 leway1980/Game 的遊戲架構共用標準 ARC-03「組裝，不複製」：
先在本資料夾複製一份經過驗證的 JS 引擎；等兩款遊戲的契約穩定後，再評估是否抽出共用引擎。
