## 1. 特殊教育法分類

特殊教育法第 3 條（身心障礙）13 類、第 4 條（資賦優異）6 類。來源：搜尋所得多份學校與法規網站轉載條文，例如 https://edu.law.moe.gov.tw/LawContentHistory.aspx?hid=1840 、https://www.lssh.tp.edu.tw/wp-content/uploads/doc/ls206/特殊教育法.pdf 。標記：【已核二手】，強度：法規轉載。條文排序在 108 年版與 112 年版不同（多重障礙與自閉症互換位置），引用條號前要對照現行版。

| 類別 | 在班上常見的樣子（一句白話；描述屬通則，非法條原文，標【憑記憶】） |
|---|---|
| 智能障礙 | 學習速度明顯比同齡慢，日常生活與學習都需要更多步驟與重複。 |
| 視覺障礙 | 看黑板或課本有困難，需要放大字、點字或座位調整。 |
| 聽覺障礙 | 聽不清老師說話，可能需要助聽器、手語或文字輔助。 |
| 語言障礙 | 說話不清楚、說不完整，或聽不懂較長的指令。 |
| 肢體障礙 | 行動、書寫或姿勢控制受限，需要無障礙空間或輔具。 |
| 腦性麻痺 | 肌肉控制困難，動作與姿勢受影響，常合併其他需求。 |
| 身體病弱 | 因慢性疾病常請假或體力不足，需要彈性出席與作業。 |
| 情緒行為障礙 | 情緒或行為反應持續過度、不合情境，造成學習與人際困難。 |
| 學習障礙 | 智力在一般範圍，但閱讀、書寫或數學某一項特別吃力。 |
| 自閉症 | 社交互動與溝通較困難，常有固著興趣、對改變或感官刺激敏感。 |
| 多重障礙 | 同時有兩種以上障礙，需要多方面支持。 |
| 發展遲緩 | 學齡前（至 6 歲）多項發展落後，尚未確定障別。 |
| 其他障礙 | 不屬以上、但有明顯學習特殊需求者。 |

資賦優異 6 類（【已核二手】，同上條文轉載）：一般智能、學術性向、藝術才能、創造能力、領導能力、其他特殊才能。一句話：在某一領域的能力或表現明顯超前，需要加深加廣的課程。描述【憑記憶】。

關於「ADHD」：《特殊教育學生及幼兒鑑定辦法》的情緒行為障礙症狀列有「注意力缺陷過動症」，與精神性疾患、情感性、畏懼性、焦慮性疾患並列。來源：搜尋摘要引全國法規資料庫 https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=H0080065 。【已核二手】，法規轉載。

### 2.5 趨勢

- 自閉症加情緒行為障礙（國中小）：105 學年約 1.3 萬 → 114 學年約 2.8 萬，約兩倍多。聯合報 https://udn.com/news/story/7315/9678291 。【已核二手】。**兩類合計**，不能拆開說哪一類增加較多；同期國中小總特教生 6.4 萬→8.6 萬，約增 34%。兩類增幅明顯高於總體（總數為同一報導的數字，增幅為我計算）。
- 「隱性障礙」（學習障礙、情緒行為障礙、自閉症等）已多於顯性：以 103 學年為例隱性 45,347 人、顯性 50,875 人（該文標題稱十年反轉、多 2.4 倍；113 學年顯性僅剩 32,408 人）。親子天下翻轉教育 https://flipedu.parenting.com.tw/article/010678 。【已核二手】。「隱性障礙」非法定分類，是實務說法。
- 自閉症「是否上升」：僅有上列兩類合計；自閉症單獨趨勢【未證實】。情緒行為障礙同。

## 6. 生日卡與研究小卡可用的事實

只列有【已核二手】以上者。年度與口徑照列，不要自行改寫數字。
