# 各年齡「今年」小卡：事實登錄表

## 查證標記
- 【已核二手】：搜尋結果摘要或新聞報導中看到該數字與來源，未開原始報告。
- 【已核二手，來源頁未對應】：數字確有出現在搜尋摘要，但無法確定是哪一個網址，網址僅為候選；上線前必補原始出處。
- 【憑記憶】：由研究者記憶列出（多為 CDC 里程碑條目），本次未連線核對；不得上線，除非核對 https://www.cdc.gov/act-early/milestones/index.html 該月齡清單。
- 【未證實】：找不到來源，不得使用。
- 證據強度：強／中／初步／現場經驗／里程碑。本檔多數為描述性調查或問卷（網路問卷非隨機抽樣），一律標「初步」；有隨機對照試驗者標「強」；發展里程碑標「里程碑」。
- 年齡對應（與 `calendar.json` 年齡公式一致）：6＝小一、7＝小二、…、11＝小六、12＝國一、13＝國二、14＝國三、15＝高一、16＝高二、17＝高三、18＝離家。
- 文字規則：不寫「比別人」「最」「較高／較低」「排名」；數字只陳述，不暗示孩子或家長「應該」如何。
