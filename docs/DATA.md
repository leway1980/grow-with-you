# 陪你長大｜比例資料

版本：0.1，2026-10-19。標「待確認」的數字是設計估計，尚未找到原始統計；實作前要補齊。
遊戲中的比例是教學抽象，不用來推論任何真實孩子。

## 2. 3C 與陪伴

| 項目 | 數字 | 來源 |
| --- | --- | --- |
| 家長未全程陪伴孩子使用 3C | 近七成；餐廳是最常讓孩子用 3C 的場合之一 | 兒福聯盟 2012 調查 |
| 11–14 歲擁有手機 | 約八成；家長有約束上網行為僅 14.7% | 兒福聯盟 2019 |
| 兒少因 3C 與家長衝突 | 約 20–25% | 兒福聯盟 2014、2015（衛福部引用） |
| 偏鄉國小高年級擁有個人 3C、使用社群 | 皆超過八成五 | 兒福聯盟 2026 城鄉調查 |
