# A2.5 時間正規化：「回合」單位清單

目的：回合不再是固定長度（嬰幼兒與幼兒園 3 個月、國小低 2–3 個月、國小中高 3 個月、高中 5–7 個月、離家 1 個月），所以每一個以「回合」為單位的量，都要換成「月」，或有意保留並說明原因。

grep：`rg -e 'turns|window|cooldown|回合|\bn\b' data js tools`（約 700 個命中，其中 `cooldownMonths` 等已換成月的鍵占一半以上，其餘是「回合」二字出現在註解與說明、`n` 是迴圈變數或計數）。每一類命中都列在下面，標「換成月」或「有意保留」。

## 規則

- 不變量（規劃者決定）：同一個策略，每個月的教養效果一樣。一張卡代表那段時間裡反覆出現的同類時刻。
- 比率：`rate_turn = 1 − (1 − r_month)^Δ`，Δ＝這個回合涵蓋的月數（時間軸的 `span`）。`r_month` 的選法：Δ＝2（舊的國小回合）時與舊的每回合值完全相同（`r_month = 1 − √(1 − r)`，資料裡存 6 位小數）。
- 劑量：一張卡的可見效果與標籤換算的隱藏變化乘上 `(Δ/2)^α`。α 在 `data/model.json` 的 `timeScale.alpha`。一次性的固定事件（池 `_fixed`）有 `scale:false`，不放大。
- 冷卻、後續卡的延遲、池開啟的長度：卡片資料原本是「回合數」，換成月數時用「今天的日曆每回合幾個月」（嬰幼兒 3、幼兒園 3、國小低 2.4、國小中高 3；跨階段的卡取平均），所以**在今天的日曆上行為不變**，日曆之後再改密度，這些月數不會悄悄跟著變。（試過用 A0 的月數：幼兒園 4、國小 2；訊號卡比例會掉到 58.8%，低於 60%。）
- 窗口：重複加速、結局的決定鏈、路線、結果軸的「最近 n 回合」都改成月窗口，2 個月的回合時與舊值相同。

## 固定事件節奏

`fixedShareByStage`（`tools/metrics.mjs`）由日曆直接算，上限在 `design-targets.json rhythm.fixedShareMax`：國小低 ≤ 60%、國小中高 ≤ 60%、國中 ≤ 50%、高中 ≤ 67%。check-design 有一列，`lint` 也會擋。

國小低原本 6/10＝60%（剛好壓線）。併進一個既有的回合：一年級的戶外教學（`fx_field_trip`）從「下學期」移到「期中之後」（和運動會同一回合，當第二張卡）。選它的原因：一年級的戶外教學最不重要（低年級多半在學校附近）、只動一個回合、仍在一年級（78 → 74 個月）。國小低變 5/10＝50%，國小中高 9/16＝56%。
